## Five frontend priorities

1. **P1 — Improve informative text contrast and size.** White CTA text on `#0b8f83` computes to **3.984:1** at 14.4–15.6px/600, below the 4.5:1 normal-text requirement. The same accent is approximately 3.60:1 on the page and 3.92:1 on the surface, affecting small informative labels. The large hero accent text is a different large-text case. Use a darker semantic text/action teal; the existing `#087166` gives white text approximately 5.89:1. Skill proficiency is only `0.61rem` (about 9.8px); raise informative metadata toward 12–13px while preserving monospaced labels. Locations: `src/index.css:39`, `src/components/Button.tsx:22`, `src/components/Skills.tsx:44`, `src/components/Editorial.tsx:58`. Standards: WCAG 1.4.3; tiny type itself is a usability concern, not an independent numeric WCAG failure. Remediation: **impeccable typeset / colorize**.

Allow the email to wrap, use shrinkable grid children, and stack the contact layout earlier or relax the note's minimum width. Locations: `src/components/Contact.tsx:13`, `:69`, `src/index.css:143`.
